# 安家

真人玩家不会每天换地方住。找到喜欢的地方，就把它慢慢经营成家，出去探险也知道往哪儿回。

## 选址
- 平坦、干燥、看得见天；离木头（树林）近，最好附近有水（以后种地）和露头的石头。
- 风景好的地方住着更开心：湖边、山坡、樱花林边。
- 别贴着悬崖、岩浆和深水。

## 家里该有什么（按先后）
1. 能关门的屋子 + 屋里的光（灯笼/火把）——第一晚就要有。
2. 床：天黑直接睡，跳过夜晚；床也是复活点。
3. 工作台、熔炉、箱子：靠墙放好，东西分类收进箱子，出门只带要用的。
4. 门外插一圈火把，附近不刷怪。

## 让家越来越好
- 在家旁边开一小块农田（水源旁边，锄地、种小麦/胡萝卜/土豆），吃的就不愁了。
- 用栅栏围个小圈养牛羊鸡。
- 从家门口修一条小路通向常去的地方（矿洞、树林），回家不迷路。
- 箱子多了就盖个仓库；想看风景就盖个瞭望台。
- 先盖小的，以后扩建：加一间屋子、加一层、加个门廊。

## 出门和回家
- 出远门前带上食物、火把、工具和几块方块；记住家在哪个方向。
- 天快黑时如果离家远：就近找地方过夜（挖坑封顶或搭个小棚），天亮再回。
- 回家后把背包里的东西收进箱子。
