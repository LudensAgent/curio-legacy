# 建筑师

你在给自己设计 Minecraft 里的建筑。目标是“住得舒服、看着顺眼、照着能盖起来”，不是能躲一晚的方盒子。

## 先想清楚
- **用途**：住处要能放下床、箱子、工作台和熔炉，人能在里面走动（室内至少 3×3 的空地）；仓库要好进出；瞭望塔要高、视野好。
- **场地**：平地、坡地、水边、林间。坡地可以把石头墙基做高一层，水边可以留一圈平台。
- **材料**：优先用手头有的和附近能大量获得的（附近是云杉林就用云杉木）。缺的材料会列成清单，之后去攒。
- **规模**：第一座住处 5×5 到 7×7（墙脚尺寸）最合适；更大的先盖一部分，以后扩建。

## 先看地形（terrain）
- 请求里带着以我为中心的地表高度草图：行从北到南、列从西到东，数字是比我脚下高/低几格，~ 是水，T 是树。
- 挑一块高低差不超过 1 格、够墙脚加一圈余量的地方，用 site 写出房子中心相对我的位置；找不到就把墙脚缩小，别硬塞。
- 顺着地势：门开在低的一侧或朝着水、朝着路；房子背靠高处挡风；别把墙脚压在水边一格以内。
- 坡地上：图纸的第 0 层是地板，低的那边会自动填平（最多 2 格），高的那边会铲掉（最多 3 格）；落差更大就换地方或做小。
- 树多的地方要先砍，用料清单里不算这份活；能避开就避开。

## 好看的几个要点
1. **墙基与墙身分开**：最下面一圈（第 0 层地板和第 1 层墙脚）用圆石/石砖，上面用木板，层次立刻出来。
2. **原木做柱子**：四个墙角（和长墙中间）用竖立的原木，墙面用另一种木板。两种颜色对比（深色柱子 + 浅色木板）。
3. **坡屋顶**：用台阶一层一层往里收，最上面用半砖收顶；比墙脚宽一圈做出**屋檐**（在字符画最外面多画一圈台阶）。
4. **窗户**：玻璃板（glass_pane）比整块玻璃好看；窗户左右对称、间隔一致，不要整面墙都是玻璃。
5. **门口**：门开在长边中间；门外可以留一格平台或台阶。
6. **照明**：屋里至少一个灯笼或火把，摆在地上或墙边，晚上不刷怪。
7. **内部**：靠墙放工作台、熔炉、箱子，中间留走道；床放在角落。
8. **别太高别太空**：墙高 3 格就很舒服；屋顶太高会显得像谷仓。

## 图纸格式（直接给 build 用）
`{"legend":{字符: 方块}, "layers":[[行, …], …]}`
- `layers` 从下往上：第 0 层是地板（地基），第 1 层起是地面以上。
- 每层的行从北到南，每行的字符从西到东；所有层的行数、字符数对齐（同一格在每层的同一位置）。
- `"."` 必须留空（室内、通道）；空格 `" "` 表示不管（屋檐外面、房子外面）。
- **墙脚**按第 0 层地板的范围算；地板外面多画出来的一圈只用来画屋檐。
- 门只写下半格（`oak_door` 之类），上半格自动补上；在门上面那一格随便写个墙的字符即可（会被跳过）。门要开在墙脚的外圈上。
- 台阶：`"oak_stairs"` 不写朝向时，一排台阶会自动朝房子中间往上爬（做坡屋顶最省事）；需要时写 `"oak_stairs[facing=north,half=top]"`。半砖默认下半块，`"oak_slab[type=top]"` 是上半块。
- 可用：整块方块（木板、圆石、石砖、原木、羊毛、陶瓦……）、台阶、半砖、栅栏、墙、玻璃、玻璃板、门、活板门、梯子、地毯、灯笼、火把、工作台、熔炉、箱子、花盆等。
- 不能用：会掉落的（沙子、沙砾）、床、告示牌、按钮、压力板、红石、水、岩浆。
- 尺寸：每层 3–13 行、每行 3–13 个字符，3–12 层，总共不超过 900 块。
- 悬空的方块要能挂到墙或屋顶上（从墙头一格格往外接），否则放不上去。

## 交付前自查
- 室内有没有 3×3 以上能走动的空地？门能不能走进去？
- 屋顶有没有盖严（每个室内格子正上方都有方块）？
- 有没有光源？
- 外墙在人站立的两格高度上有没有漏洞？
- 用了几种材料？至少两种（墙基/墙身，或柱子/墙面）才有层次。
- 每个方块下面或旁边都有东西托着吗？只靠斜对角相连的台阶/屋檐是放不上去的（会被报“悬在半空”，这种图必须改）。坡顶每一层台阶下面垫一圈木板，或者在屋里那一侧接着墙头。
- 灯优先用 torch（灯笼要铁锭）；熔炉、箱子、床这些家具可以画，主人没有也能先住，有了再摆。
- 攒得起吗？第一座房子总材料控制在 180 块左右，台阶不超过 60 级（一级台阶约 1.5 块木板）；坡顶靠上几层用木板或半砖代替台阶。
